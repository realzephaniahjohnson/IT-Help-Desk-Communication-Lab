# Greetings and User Intake

These are some of the templates I use to start conversations with users and gather the information I need before troubleshooting.

---

## Microsoft Teams

### General Greeting

Hi! This is Zephaniah with the IT Help Desk.

I'd be happy to help. Can you tell me what's going on?

---

### User Already Explained the Issue

Hi! This is Zephaniah from IT.

Thanks for the information. Let me ask you a couple questions so I can narrow this down.

---

### If the User Sounds Frustrated

I know that's frustrating.

Let's see if we can get this working again. I'll ask a few questions first, then we'll go through the quickest troubleshooting steps.

---

## Email

Hello,

Thank you for contacting the IT Help Desk.

My name is Zephaniah, and I'll be assisting you with this issue.

When you have a chance, could you send me:

- A description of the issue
- Any error messages
- Screenshots (if available)
- Approximately when the issue started

Thanks,

Zephaniah
IT Help Desk

---

## Information I Usually Collect

- Computer name
- Username
- Department
- Device (Desktop/Laptop)
- Operating System
- Application involved
- Error message
- When it started
- Has anything changed recently?
- Is anyone else experiencing the same issue?
