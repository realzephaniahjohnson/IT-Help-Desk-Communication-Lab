# Ticket Documentation Templates

Examples of documentation I would leave in a ticket after working with a user.

---

## Initial Note

User reports Outlook will not open.

Issue started this morning.

No error message displayed.

Beginning troubleshooting.

---

## Progress Update

Confirmed issue with user.

Restart completed.

Issue still present.

Currently reviewing Outlook processes and application status.

---

## Resolution

Restarted Outlook and cleared the unresponsive process.

User tested the application successfully.

Issue resolved.

---

## Escalation Note

Initial troubleshooting completed.

Issue still occurring.

Escalating to Tier 2 for additional investigation.

Attached screenshots and troubleshooting notes.

---

## Final Ticket Summary

Issue:
Outlook would not open.

Root Cause:
Unresponsive Outlook process.

Resolution:
Restarted Outlook and terminated the hung process.

User confirmed functionality.

Ticket closed.
